GitHub, VS Code Mermaid extension, or https://mermaid.live).

| File | Diagram |
|---|---|
| `system_architecture.mmd` | Figure 1 — Overall seven-layer runtime architecture |
| `data_flow.mmd` | Figure 2 — End-to-end data flow |
| `control_flow.mmd` | Figure 3 — TwinTrust-AP control/decision flow |

Part V) and should be kept visually consistent with any diagrams
regenerated later for the IEEE paper.
